# Horizon API

Backend API for the Horizon Autonomous Enterprise Infrastructure Recovery Platform.
Built with FastAPI and Python 3.11+.

## Setup

1. Make sure Python 3.11+ is installed.
2. Install dependencies (e.g. using pip, pipenv, poetry, or uv).
3. Copy `.env.example` to `.env` and fill in credentials.
4. Run `uvicorn src.main:app --reload` to start the development server.
